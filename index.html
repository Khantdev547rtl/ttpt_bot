Key Features

Built specifically for study groups, classrooms, and project teams.

Multi-Process Scheduler

Configure automated scheduled reminders for target exam dates or project deadlines with daily countdowns (Left Time).

Weekly Homework Sync

Keep track of weekly subject assignments with automated resets every Monday at 00:00 (Asia/Yangon time).

Neumorphic Dashboard

Manage all processes, dates, reminder times, and homework lists via an integrated web interface (/web).

AI Vocabulary Lookup

Instant English word breakdowns (parts of speech, Myanmar translations, synonyms, and examples) powered by Coze AI.

TTS Pronunciation

Listen to natural English audio pronunciation directly inside group chats using /listen [word].

Myanmar Timezone Native

Synchronized precisely with Asia/Yangon (UTC+6:30) time standards for accurate schedule triggers.

Bot Commands

Interactive group commands ready out of the box.

Command Description
/start Welcome message and direct link to the Web Dashboard.
/menu Displays all active processes, target date countdowns, and homework lists.
/web Opens the Neumorphic Web Dashboard URL for managing group settings.
/listen <word> Generates a voice message with the English pronunciation of the requested word.
/vocab <word> Looks up deep linguistic breakdown and Myanmar translations for an English word.
@bot_username <word> Mentioning the bot in a group chat triggers an automatic vocabulary lookup.
