How to Use TTPT Bot

Get up and running in your Telegram group in under 2 minutes.

1

Add Bot to Your Telegram Group

Add @ttpt_reminderbot to your target Telegram study group or class group chat.

2

Configure via Neumorphic Dashboard

Type /web in the group or open the Web Dashboard, enter your Group Chat ID, and set up processes, exam dates, alert trigger times, and weekly homework assignments.

3

Lookup Vocabulary & Audio Pronunciation

Use /vocab [word] or mention the bot (@ttpt_reminderbot resilient) to query Coze AI, or type /listen [word] to receive an instant English pronunciation audio clip.

Complete Command Reference

Interactive group commands ready out of the box.

Command Description
/start Welcome message and direct link to the Neumorphic Web Dashboard.
/menu Displays all active processes, target date countdowns, and homework lists.
/web Opens the Neumorphic Web Dashboard URL for managing group settings.
/listen <word> Generates a voice message with the English pronunciation of the requested word or phrase.
/vocab <word> Looks up deep linguistic breakdown and Myanmar translations for an English word.
@bot_username <word> Mentioning the bot in a group chat triggers an automatic AI vocabulary lookup.
/help Displays the help guide and command list inside Telegram.
