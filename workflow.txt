Workflow:

1. User sends /countdown command with date and info
2. Bot stores the data in KV store
3. Bot sends confirmation message
4. Bot checks via Cron trigger if it's time to send reminder
5. If it's time, bot sends reminder message to group with random note and mentions
6. Bot continues checking until countdown reaches 0

--/help

1. Show all commands

--/countdown

1. User sends /countdown command with date and info
2. Bot stores the data in KV store
3. Bot sends confirmation message

--/remind

1. User sends /remind command with time
2. Bot stores the data in KV store
3. Bot sends confirmation message

--/setnote

1. User sends /setnote command with note
2. Bot stores the data in KV store
3. Bot sends confirmation message

--/notes

1. Bot sends all notes

--/status

1. Bot sends status of countdown

--/cancel

1. Bot cancels the countdown

--/delete

1. Bot deletes the countdown
